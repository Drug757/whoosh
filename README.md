# Whoosh project

## 1. Краткое описание инструмента
Whoosh — это библиотека для реализации поиска по тексту.

## 2. Цель изучения
Понять, как работают поисковые системы.

## 3. Описание реализованной задачи
Создан индекс и выполнен поиск по тексту.

## 4. Инструкция по запуску
1. Установить:
   ```
   pip install whoosh
   ```
2. Запустить:
   ```
   python main.py
   ```
  
## 5. Общие выводы
Whoosh позволяет реализовать поиск без сложных систем.

# Техническое задание

## 1. Описание задачи
Необходимо реализовать программу, которая создаёт простой индекс текстовых данных и выполняет поиск по ним с использованием библиотеки Whoosh.

## 2. Цель работы
Изучить принципы индексации и поиска текста.

## 3. Функциональные требования
Программа должна:
- создать индекс  
- добавить несколько текстовых записей  
- выполнить поиск по ключевому слову  
- вывести результат  

## 4. Нефункциональные требования
- код должен быть понятным  
- поиск должен работать быстро  
- структура должна быть логичной  

## 5. Ограничения и допущения
- небольшой набор данных  
- один файл  
- простой текст
